# Chess

Web-based chess app built with React + Vite and Stockfish.

## Features
- Human vs Computer & Human vs Human
- Move history, Undo / Redo
- Promotion chooser
- Hover legal-move hints and last-move arrows
- Engine evaluation via Web Worker (Stockfish)

## Quick start

Install:   npm install

Run dev server:    npm run dev

Build:    npm run build
