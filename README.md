# Chess

Web-based chess app built with React + Vite and Stockfish.

## Features
- Human vs Computer & Human vs Human
- Move history, Undo / Redo
- Promotion chooser
- Hover legal-move hints and last-move arrows
- Engine evaluation via Web Worker (Stockfish)

## Quick start

Install:

```bash
npm install
```

Run dev server:

```bash
npm run dev
```

Build:

```bash
npm run build
```

Run smoke tests:

```bash
node test-features.js
```

## Deploy

Deploy to Vercel or Netlify (auto-deploy from GitHub). For Vercel, connect your repo and it detects Vite.
